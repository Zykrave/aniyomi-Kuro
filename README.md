# Kuro

### A modern, redesigned media library manager and player for Android.

</div>

## About

Kuro is a versatile media library manager and player designed for anime and manga enthusiasts. Built on a flexible, extension-based source system, Kuro allows users to easily integrate and manage their own content sources, providing a centralized hub for all their favorite media.

What sets Kuro apart is its commitment to a modern, high-quality user experience. The app features a redesigned UI with a sleek dark aesthetic, utilizing a near-black background accented by striking crimson and electric-blue elements. Its card-based layouts and custom onboarding process are crafted to ensure that navigating your library is as intuitive as it is visually pleasing.

Focused on ease of use and performance, Kuro offers a refined alternative to typical media apps, bringing a contemporary feel to the powerful underlying architecture of the extension system.

## Built With

Kuro is developed natively in Kotlin using Android Studio and Jetpack Compose. It is a specialized fork built upon an established open-source anime and manga codebase, with a primary focus on completely rebuilding the UI and UX from the ground up. While the interface has been entirely reimagined to meet modern standards, Kuro retains the robust underlying extension APIs and library-management systems that provide its core functionality.
